Authentication Mental Map

Swing Login Screen
        ↓
AuthController.login(email, password)
        ↓
AuthService.authenticate(...)
        ↓
JAAS LoginContext
        ↓
EmailPasswordLoginModule
        ↓
JsonUserRepository → users.json
        ↓
PasswordHasher.verify()
        ↓
Subject populated
        ↓
AppSession.setSubject()

Responsibilities Summary:
- AuthController: GUI-facing API
- AuthService: JAAS wrapper
- LoginModule: credential verification
- Repository: user lookup
- AppSession: current authenticated user
